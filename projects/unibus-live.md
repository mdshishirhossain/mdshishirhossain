# UniBus Live — University Bus Tracking System

[← Back to profile](../README.md)

**Final-year academic project · NPI University of Bangladesh · 2026**

## Overview

UniBus Live is a GPS-based transport tracking system designed to help passengers monitor university buses and help staff coordinate routes, stops, trips, and schedules. The project includes a web administration interface and mobile workflows for drivers and passengers.

## What the system covers

- **Administration:** Bus, route, stop, schedule, and trip management.
- **Drivers:** Starting trips and sharing GPS location updates.
- **Passengers:** Viewing active trips, live bus locations, and estimated arrival times.
- **Real-time communication:** Location and trip-state updates and transport notifications.
- **Project evaluation:** Android builds were pilot-tested and the project was presented at a university project fair.
