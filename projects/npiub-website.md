# NPI University of Bangladesh — Website Redevelopment

[← Back to profile](../README.md)

**Institutional website development · NPI University of Bangladesh**

## Overview

A Laravel-based redevelopment of the university website, designed to present institutional information and provide staff with tools for managing site content.

## Development scope

- Public-facing university pages and responsive interface.
- Administrative management of notices, news, events, departments, and faculty information.
- Role-based administrative permissions.
- Media and content management features.
- Migration workflows for existing website data.
- Application testing, code-quality checks, and staging/deployment preparation.

## Technology

| Area | Stack |
| --- | --- |
| Application | PHP, Laravel |
| Administration | Filament |
| Database | MySQL / MariaDB |
| Frontend | Blade, Tailwind CSS, Alpine.js / Livewire |
| Quality tooling | Pest, Laravel Pint, Larastan |

## Deployment and ownership notes

The private repository documents a **HostGator/cPanel staging workflow**, with deployment preparation and a production cutover checklist. That documentation should not be read as independent confirmation that the rebuilt application itself has completed production cutover.

The university's existing website is in operation, but the precise production status of this redevelopment should be confirmed from its hosting environment before public launch claims are made.

The implementation source remains private. No credentials, administrative links, configuration secrets, or client data are shared in this case study. Public screenshots and links should only be added with appropriate institutional permission.
